# Welcome To The Course

This course develops the official Platform APIs and Provisioning Infrastructure objectives for Certified Cloud Native Platform Engineering Associate (CNPA). The certification uses a multiple-choice examination. The course is independently authored and does not claim to simulate the examination. At the end you can explain and operate the Kubernetes reconciliation loop, define a custom resource API, provision infrastructure through a claim and work with an operator.

Each section starts with its own introduction and learning outcomes. Each module has a landing page, several reading parts, a playground, a graded lab and a summary. Each section ends with a capstone lab and a knowledge check, and the course ends with a final domain quiz.

The example workloads use the names `scout`, `probe`, `shuttle` and `drifter` in the namespaces `starfleet` and `outpost`. The names carry no technical meaning.

Read each part, run the commands in the playground and then solve the lab that follows. A playground is a clean cluster with no task and no grade. A lab is graded against a live cluster. Technical pages remain draft for review.
