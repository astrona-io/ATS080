# Summary

A custom resource definition establishes an API kind and schema, while a controller implements its operational meaning. Specifications express requested intent and status reports observed progress. Validation, authorization and version policy make the API safe to consume, but do not provision resources by themselves. A self-service contract should expose useful states and limited choices while keeping secrets and provider-specific complexity behind appropriate boundaries.
