# APIs for Self-Service Platforms (CRDs)

This section covers aPIs for Self-Service Platforms (CRDs). It develops custom Resource Schemas, Status And Self-Service Contracts through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain a CRD as an API contract rather than an implementation.
- Distinguish desired specification, observed status and reconciliation.
- Reason about validation, versioning and tenant permissions.
