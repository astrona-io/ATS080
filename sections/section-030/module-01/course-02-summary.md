# Summary

Kubernetes-based provisioning uses declared requests and controllers to manage external infrastructure through provider APIs. Provider identity and tenant policy constrain the authority exercised on a user's behalf. Readiness and connection delivery follow actual provider outcomes rather than API acceptance alone. Persistent-resource retention, deletion and partial failure need explicit contracts. A declarative claim improves management but does not automatically back up data or make external operations reversible.
