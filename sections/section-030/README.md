# Infrastructure Provisioning with Kubernetes

This section covers infrastructure Provisioning with Kubernetes. It develops infrastructure Claims, Provider Identities And External Lifecycle through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Trace a platform claim through a controller to an external provider.
- Explain provider credentials, readiness and connection delivery.
- Reason about retention, deletion and partial failures.
