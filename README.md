# Platform APIs and Provisioning Infrastructure (ATS080)

Certified Cloud Native Platform Engineering Associate (CNPA): Platform APIs and Provisioning Infrastructure, worth 12% of the official curriculum. This course belongs to ATP016.

Developed reading explains mechanisms, responsible components, examples and limits. Each module has a playground and a graded lab, each section has a capstone lab and a quiz, and the course ends with a final domain quiz. Technical content remains draft. Labs and playgrounds are UNTESTED: they were built with static checks only.
